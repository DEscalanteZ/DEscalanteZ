# David Escalante

Founder and CEO of three Spanish companies working across entertainment, digital media and applied science. I run them with teams of AI agents that I direct rather than code by hand.

**What I work on**
- 🤖 **Agentic operations:** running production automation with AI agents, where every job is judged by what it produced, not by whether it ran.
- 🎙️ **Conversational AI:** real-time voice and chat systems.
- 🧬 **Applied data science:** biostatistics and research tooling for health and life sciences.
